## four-on-the-floor

ID: `rhythm-four-on-the-floor`. Назначение: style.

**Что означает:** Бочка на каждой из четырёх долей такта; характерная танцевальная опора.

**Как понимать действие:** Описывает группировку и размещение музыкальных событий относительно пульса.

**Где применять:** В Style вместе с темпом и характером ударных, если они нужны.

**Настройки:** [Ощущение](../settings.md#tempoFeel), [Плотность грува](../settings.md#grooveDensity), [Барабаны](../settings.md#drumFeel)

**Примеры:**

### В описании звучания (style)

```text
four-on-the-floor
```

Минимальный пример одного музыкального пожелания; добавьте собственный жанровый контекст.

### С контекстом (style)

```text
four-on-the-floor, steady pulse
```

Пара пожеланий для отправной точки. Меняйте один элемент и сравнивайте результат на той же модели.

**Ограничения:** Размер, подразделение и BPM не взаимозаменяемы. Точное исполнение сложной полиритмии не гарантируется. Внутреннее устройство модели неизвестно. Музыкальное объяснение не доказывает точное выполнение запроса.
