## avoid: trap

ID: `avoid-avoid--trap`. Назначение: exclude.

**Что означает:** Просьба не использовать трэп-аранжировку. В поле Exclude предлагается переносить «trap» без префикса avoid:.

**Как понимать действие:** Нежелательный элемент задаётся в отдельном поле Exclude, а не как обещание стопроцентного запрета.

**Где применять:** Предлагаемое назначение: Exclude. Сейчас приложение добавляет avoid: в Style; миграция ещё не выполнена.

**Настройки:** [Где избегать](../settings.md#avoidScope), [Жесткость](../settings.md#strictness)

**Предлагаем исправить:** Убрать неподтверждённые strictness/avoidScope; отдельное поле Exclude, без скрытой силы запрета.

**Примеры:**

### Отдельное исключение (exclude)

```text
trap
```

Предлагаемый экспорт в Exclude. Не вставлять этот фрагмент как слова песни.

### Проверка противоречий (workflow-note)

```text
Сравните исключение с составом каждой секции: не запрещайте глобально то, что хотите услышать в припеве.
```

Это памятка, не текст для копирования в Suno.

**Ограничения:** Не исключайте глобально инструмент, нужный в припеве. Не переносите отрицание в Lyrics как обязательные слова песни. Внутреннее устройство модели неизвестно. Музыкальное объяснение не доказывает точное выполнение запроса.

**Доказательства:** Музыкальное описание; специальная поддержка этого синтаксиса не подтверждена. Аудиопроверка нами не проводилась. Контекст: [S14: Exclude elements](https://help.suno.com/en/articles/3161921). Эти ссылки не доказывают выполнение каждого тега.

**Псевдонимы каталога:** нет.
