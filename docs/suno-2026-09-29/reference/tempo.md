## 66 BPM

ID: `tempo-66-bpm`. Назначение: style.

**Что означает:** Пожелание пульса 66 BPM: 66 долей в минуту. Не задаёт рисунок ударных, размер такта или гарантированную скорость готового аудио.

**Как понимать действие:** Число или словесный темп описывает желаемый пульс, а не программирует транспортную сетку генератора.

**Где применять:** В Style рядом с описанием ритма. Не меняйте одно число на другое без осмысленного музыкального контраста.

**Настройки:** [Ощущение](../settings.md#tempoFeel), [Плотность грува](../settings.md#grooveDensity), [Барабаны](../settings.md#drumFeel)

**Примеры:**

### В описании звучания (style)

```text
66 BPM
```

Минимальный пример одного музыкального пожелания; добавьте собственный жанровый контекст.

### С контекстом (style)

```text
66 BPM, steady pulse
```

Пара пожеланий для отправной точки. Меняйте один элемент и сравнивайте результат на той же модели.

**Ограничения:** Проверяйте фактический темп. Half-time/double-time могут менять ощущение без изменения BPM. Внутреннее устройство модели неизвестно. Музыкальное объяснение не доказывает точное выполнение запроса.

**Доказательства:** Музыкальное описание; специальная поддержка этого синтаксиса не подтверждена. Аудиопроверка нами не проводилась. Контекст: [S14: Exclude elements](https://help.suno.com/en/articles/3161921). Эти ссылки не доказывают выполнение каждого тега.

**Псевдонимы каталога:** нет.
