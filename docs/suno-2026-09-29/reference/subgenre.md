## dance-pop

ID: `subgenre-dance-pop`. Назначение: style.

**Что означает:** Поп-песня с танцевальной ритм-секцией и заметным припевом.

**Как понимать действие:** Уточняет основной жанр через характерную ритмику, тембры или способ развития.

**Где применять:** В Style рядом с основным музыкальным направлением.

**Настройки:** [Энергия](../settings.md#styleEnergy), [Фактура](../settings.md#styleTexture), [Аранжировка](../settings.md#styleArrangement)

**Примеры:**

### В описании звучания (style)

```text
dance-pop
```

Минимальный пример одного музыкального пожелания; добавьте собственный жанровый контекст.

### С контекстом (style)

```text
dance-pop, instrumental
```

Пара пожеланий для отправной точки. Меняйте один элемент и сравнивайте результат на той же модели.

**Ограничения:** Не накапливайте близкие названия без понимания, что каждое должно изменить. Внутреннее устройство модели неизвестно. Музыкальное объяснение не доказывает точное выполнение запроса.
